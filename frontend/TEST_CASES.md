# 塔罗牌小程序测试用例

## 一、构建与启动

- [ ] TC-01: 执行 `npm run build:h5` 成功，无编译错误。
- [ ] TC-02: 执行 `npm run dev:h5` 后首页可在 `http://localhost:5173/` 打开。
- [ ] TC-03: H5 控制台无阻塞流程的 `error`。
- [ ] TC-04: 主要页面在移动端宽度下无横向滚动、按钮无遮挡。

## 二、首页与 i18n

- [ ] TC-05: 首页中文默认显示 `塔罗梦语`、`每日一抽`、`选择牌阵`、`开始洗牌`。
- [ ] TC-06: 点击左上角语言按钮后切换英文，首页显示 `Tarot Dream`、`Daily Card`、`Choose a Spread`、`Start Shuffling`。
- [ ] TC-07: 再次点击语言按钮切回中文。
- [ ] TC-08: 刷新页面后保留上次选择的语言。
- [ ] TC-09: 点击 `牌意查询/Card Meanings` 显示敬请期待/Coming soon 提示。
- [ ] TC-10: 点击登录入口进入登录页。

## 三、登录页

- [ ] TC-11: 中文模式显示登录后同步、欢迎回来、微信一键登录、游客访问。
- [ ] TC-12: 英文模式显示 sync/welcome/WeChat Quick Login/Continue as Guest。
- [ ] TC-13: 后端不可用时点击登录不写入假登录态，并提示游客模式。
- [ ] TC-14: 点击游客访问返回首页。

## 四、抽牌主流程

- [ ] TC-15: 首页选择单张牌阵并输入问题，点击开始洗牌进入抽牌页。
- [ ] TC-16: 抽牌页显示新牌背 `/static/images/card-back-moon-strong-border.png`。
- [ ] TC-17: 洗牌动画结束后可点击牌堆抽牌。
- [ ] TC-18: 单张牌阵抽 1 张后显示完成状态。
- [ ] TC-19: 三张牌阵需要连续抽 3 张后才显示完成状态。
- [ ] TC-20: 点击查看解读进入结果页，并保存历史记录。
- [ ] TC-21: 英文模式下抽牌页显示 `Shuffling`、`Tap to draw card`、`Draw complete`、`View Reading`。

## 五、结果页

- [ ] TC-22: 结果页显示牌阵名、问题、时间、牌面、正逆位、关键词和核心含义。
- [ ] TC-23: 英文模式下牌名优先显示 `nameEn`，正逆位显示 `Upright/Reversed`。
- [ ] TC-24: 无效 `id` 进入结果页时显示空状态并可重新开始。
- [ ] TC-25: 点击获取基础/AI 解读后有加载状态，失败时回退到基础解读或明确提示。
- [ ] TC-26: 点击分享复制文本，toast 显示成功。
- [ ] TC-27: 解读内容中的 HTML 已转义，输入 `<script>` 不会执行脚本。

## 六、每日一抽

- [ ] TC-28: 首次进入每日一抽显示牌背和抽取按钮。
- [ ] TC-29: 点击抽取后显示今日牌、正逆位、今日指引、关键词。
- [ ] TC-30: 同一天重复进入不会重复抽新牌。
- [ ] TC-31: 英文模式下显示 `Daily Card`、`Today's Guidance`、英文月相和英文指引。
- [ ] TC-32: 点击查看详情进入牌详情页。
- [ ] TC-33: 点击分享日运复制文案并显示 toast。

## 七、历史记录

- [ ] TC-36: 点击历史记录进入对应结果页。
- [ ] TC-37: 空历史显示空状态和开始占卜按钮。
- [ ] TC-38: 清除所有记录弹窗确认后历史列表清空。
